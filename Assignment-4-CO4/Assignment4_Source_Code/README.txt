ASSIGNMENT 4 - CO4 SOURCE CODE

Open this folder in Visual Studio Code. Each task has its own .cpp file.

Compile each file from the VS Code terminal (PowerShell) using:

g++ -std=c++17 -Wall -Wextra Task01/task01_staff_hierarchy.cpp -o task1
g++ -std=c++17 -Wall -Wextra Task02/task02_virtual_inheritance.cpp -o task2
g++ -std=c++17 -Wall -Wextra Task03/task03_constructors_members.cpp -o task3
g++ -std=c++17 -Wall -Wextra Task04/task04_polymorphism.cpp -o task4
g++ -std=c++17 -Wall -Wextra Task05/task05_cart_this_pointer.cpp -o task5
g++ -std=c++17 -Wall -Wextra Task06/task06_vehicle_rental_fleet.cpp -o task6

Run on Windows PowerShell:
.\task1.exe
.\task2.exe
.\task3.exe
.\task4.exe
.\task5.exe
.\task6.exe

Important:
- These are separate source files. Do not paste all files into one .cpp file.
- The assignment also requires written analysis, diagrams, predictions, screenshots and evidence.
- Compile and run each program yourself. Save screenshots of actual output in the matching Task folder.
