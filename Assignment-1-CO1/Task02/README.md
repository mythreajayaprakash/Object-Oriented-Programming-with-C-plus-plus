# Task 2 – Tokens and constants
Token categories: keywords (`class`, `enum`, `if`), identifiers (`SmartCard`, `balancePaise`), constants (`5000`, `20`), operators (`+`, `>=`, `&&`), punctuators (`{}`, `()`, `;`). `#define` is preprocessor substitution without type/scope safety; `const` is read-only; `constexpr` enables compile-time evaluation and is preferred for fixed fares. `enum class Zone { Inner, Middle, Outer };` scopes names and prevents implicit integer conversion. Naming: PascalCase types, UPPER_SNAKE_CASE constants, lowerCamelCase variables/functions. Macros do not normally change runtime cost but lose type checking and C++ scope.
