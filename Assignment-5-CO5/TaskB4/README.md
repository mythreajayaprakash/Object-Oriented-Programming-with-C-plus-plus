This extension adds MaternityBill and CorporateTieUp without modifying the existing Bill or Payer interfaces. The example corporate coverage percentage is an illustrative assumption (70%), not a rate specified in the assignment. A production system would need audited configuration, currency-safe integer minor units, patient/claim identity, persistence, authorization, logging, idempotency and tested policy rules. A plug-in/configuration design reduces code deployment for rate-only changes but requires validation and safe rule interpretation.
