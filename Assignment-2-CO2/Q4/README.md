# Q4 – Savings account mini-statement
The account number, balance, transaction array, count and circular index are private. Deposit/withdraw validate inputs and update the account. `miniStatement` is defined outside the class with the scope resolution operator. Shifting a full array costs O(k) per new transaction; a circular index makes insertion O(1), with O(k) fixed storage and O(k) statement traversal. Changing history size from 10 to 50 changes capacity, not the algorithm. A deque also supports efficient push_back/pop_front, but a fixed circular buffer has predictable storage.
