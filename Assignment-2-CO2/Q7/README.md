# Q7 – Diagnose, redesign and validate
Selected limitation: when a fixed transaction array is full, shifting the existing k-1 elements for each insertion costs O(k). Objective: retain the most recent 50 transactions with O(1) insertion and the same fixed storage. Redesign: use a circular buffer and overwrite the oldest entry, advancing a modulo-capacity index. Chronological display must start at the oldest retained position. The benchmark runs both approaches with the same insertion count and checks that their newest values agree. Prediction: circular insertion should be faster after the buffer fills. Run repeated local measurements and record actual results. Shifting may remain simpler for very small histories or rare insertions.
