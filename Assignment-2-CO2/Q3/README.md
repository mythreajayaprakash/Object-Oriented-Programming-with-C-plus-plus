# Q3 – Default arguments and function overloading
The original overload set is ambiguous for a one-argument call because both charge(double) and charge(double,bool=false,bool=false) can accept it. The revised set has one double overload with trailing defaults, an int grams overload and a Parcel overload. The six calls in the program demonstrate exact match and promotion. Exact matches are preferred over promotions, which are preferred over standard conversions. Default arguments must be trailing. Overload resolution happens at compile time and adds no run-time dispatch. A Parcel structure can be easier to extend when options grow.
