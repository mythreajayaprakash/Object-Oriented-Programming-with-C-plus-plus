# Q6 – Friend and inline functions
Friend functions are non-members granted access to private hours/minutes. They are called as ordinary functions and suit symmetric operations on two Time objects. Making fields public would weaken encapsulation. `inline` does not guarantee machine-code substitution; it also permits suitable definitions in multiple translation units. The program completes both TODOs and tests 09:45–13:10 (205 minutes), identical times and a pair across noon. Benchmark commands: `g++ -std=c++17 -O0 -Wall -Wextra q6_friend_inline.cpp -o q6_O0` and the same with `-O2`. Run repeatedly and record your own measurements; do not treat one run as definitive.
