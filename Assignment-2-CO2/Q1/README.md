# Q1 – Call by value, reference and pointer
The value parameter is a copy, the reference aliases the caller's variable, and the pointer refers to the caller's object through its address. Only the reference and pointer update caller state. `bigger` returns a reference to an existing argument, so its result can be assigned to. `show(1)` uses defaults 5 and 10; `show(1,2)` uses default 10; the three-argument call uses none. The completed concession function updates the caller by reference. Returning the calculated fee is an alternative with clearer value semantics. Scalar calls are O(1); passing a large object by value copies its contents, while reference/const-reference avoids that copy.
