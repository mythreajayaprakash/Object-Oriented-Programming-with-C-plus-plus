# Q7 – Complex-number class for AC impedance
Complex stores real and imaginary parts and provides default, real-only and real/imaginary constructors. It overloads +, -, *, /, == and <<, and computes magnitude. Series impedance is the sum of resistor, inductor and capacitor impedances. Parallel impedance is `(Z1 * Z2) / (Z1 + Z2)`. Division checks a zero denominator and throws `std::domain_error`. Verify calculations by hand and compare with `std::complex<double>`; the custom class uses two doubles and O(1) time/space per arithmetic operation, but needs careful numerical and edge-case handling.
