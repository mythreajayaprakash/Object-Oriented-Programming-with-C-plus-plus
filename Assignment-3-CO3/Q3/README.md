# Q3 – Dynamic constructors and destructors
The Event constructor allocates an array of row pointers and then one bool array per row. The destructor deletes every row with `delete[]` and then the row-pointer array. Local and block-scope objects are destroyed automatically at scope exit; a heap object is destroyed only when `delete` is called. Forgetting delete leaks memory; using scalar delete instead of delete[] is undefined behaviour. Destructors take no arguments and cannot be overloaded. A zero-row event is supported. The row-pointer design uses rows+1 allocations; a single flat block needs one allocation and index `r * seatsPerRow + s`, while a vector-of-vectors has its own nested allocations. Run with AddressSanitizer and record actual memory/timing evidence.
