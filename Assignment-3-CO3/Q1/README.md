# Q1 – Constructors and constructor overloading
The Book class provides default, title-only, title-and-count, and full constructors. Delegation funnels construction through one validating constructor, so negative copy counts are rejected in one place. Member initializer lists initialise members directly; members are initialised in declaration order, regardless of the order written in the list. If no constructor is declared, the compiler may generate a default constructor; declaring constructors can suppress that implicit default constructor. `explicit` prevents unintended implicit conversions. Creation is O(1) for the fixed-size metadata used here. For the experimental evidence, temporarily remove the default constructor and try `Book books[3];`; capture the compiler diagnostic. To observe `-Wreorder`, create a separate deliberately misordered demonstration and compile with `-Wreorder`; do not break the submitted main program.
