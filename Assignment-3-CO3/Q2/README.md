# Q2 – Copy constructors: shallow and deep copies
This version implements the Rule of Three: copy constructor, copy assignment and destructor. Each copy owns its own array, so changing one prescription does not alter another and destruction does not double-delete shared storage. The deliberately unsafe shallow-copy version is not executed in this package because it has undefined behaviour; create a separate copy for the required sanitizer demonstration and capture the report. The compiler-generated copy constructor is safe for value members and standard containers, but not for a raw owning pointer. Copying n medicine names is O(n) time and O(n) extra space; passing by const reference avoids the copy. The included harness prints local copy timings; run repeatedly and report your actual results under AddressSanitizer.
