# Q6 – Text class and operator-overloading rules
Text owns a dynamically allocated null-terminated character array and implements constructor, deep-copy constructor, copy assignment with self-assignment guard, destructor, concatenation, equality/inequality and stream insertion. Operators that cannot be overloaded include `::`, `.`, `.*`, `?:` and `sizeof`. Overloading cannot change precedence or arity, and at least one operand must be a user-defined type. `operator=` must be a member. Friend functions are useful when a non-member needs private access or symmetric operands. Compare with `std::string` and run AddressSanitizer locally; this implementation is educational and not a replacement for the standard library.
