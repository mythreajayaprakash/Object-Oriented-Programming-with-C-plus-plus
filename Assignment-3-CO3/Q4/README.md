# Q4 – Arithmetic and stream operator overloading
Money stores integer paise. `+` returns a new value, while `+=` modifies the left operand and returns `*this` by reference to support chaining. Equality and ordering are members; stream insertion/extraction are friends/non-members because the left operand is an ostream/istream. `a + b` is translated to `a.operator+(b)` for this member overload. The program tests Rs 0.75 + Rs 0.50 and a negative result. Multiplication of one Money value by another is generally not meaningful; multiplication by a scalar could be defined. All listed operations are O(1).
