# Q5 – Increment, comparison and subscript operators
Prefix `++` has no dummy parameter and returns a reference to the incremented object. Postfix `++(int)` uses a dummy int parameter and returns the old value by copy. The program shows `a=t++` receiving the old time and `b=++t` receiving the new time. Playlist has checked const and non-const subscript overloads; invalid negative and size indices throw `std::out_of_range`. Time is stored as total seconds, so 59:59 rolls to 1:00:00. Run the requested 10-million-iteration prefix/postfix benchmark at `-O0` and `-O2` locally and record measurements.
